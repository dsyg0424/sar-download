# 下载器交互优化完成记录

日期：2026-10-30

## 本次完成
1. 任务快照使用请求序号和事件水位；忽略过期快照，保留请求期间新增的任务，仍通过删除墓碑防止已删除记录复活。快照按 Map 合并，复杂度由 O(n²) 降为 O(n)。
2. 添加任务成功后先按服务端返回 ID 启动，状态刷新不再作为启动前置条件。启动失败仍刷新已创建记录；同步失败单独提示且不覆盖先前错误。
3. 新增“取消检索”按钮和 Rust cancel_sar_search 命令。独立查询 ID 精确取消，处理取消先于注册到达的情况；取消时丢弃正在等待的检索 future。前端等待原请求结束后恢复上次结果和勾选，忽略晚到进度及结果，取消失败则保持查询可用。
4. 下载抽屉折叠或没有活动任务时停止250ms显示定时器；保留筛选与组件状态，重新打开后恢复刷新。速度采样仍接收任务事件。尚未加入列表虚拟滚动。
5. GeoJSON 导出改为完整异步回调，增加同步互斥与导出中状态；重复点击不会重复打开保存流程，失败后恢复按钮并显示原因。
