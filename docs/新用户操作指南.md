# 地枢遥感 SAR数据可视化下载平台｜新用户操作指南

## 1. 第一次使用：完成一次下载

1. 打开桌面应用，点击标题栏右侧的 **设置**。
2. 选择保存目录，填写 Earthdata 用户名和密码，点击 **保存设置**。
3. 点击 **手动框选**，在地图上拖出一个较小的矩形研究区。
4. 设置开始日期、结束日期和 **产品类型**；初次使用可先选择一种产品和较短时间段。
5. 点击 **检索**，等待检索结束；核对结果的日期、轨道、极化和覆盖范围。
6. 勾选需要的影像，点击 **下载所选（N 景）**，任务会加入下载中心并尝试自动开始。
7. 点击标题栏的 **下载** 查看进度，等任务显示 **已完成**。
8. 点击任务卡片上的文件夹按钮，打开保存目录。

**完成标志：任务状态为“已完成”。** 文件传输结束后还会校验和保存，不能只看传输字节数或进度接近 100%。

## 2. 使用前准备

- 准备可用的 Earthdata 账号。公开目录检索通常不需要账号，文件下载需要有效账号和数据服务访问权限。
- 为下载目录预留足够空间；整景影像可能较大，下载与校验期间还会使用临时文件。

## 3. 认识主界面

| 位置 | 功能 |
|---|---|
| 顶部标题栏 | 应用名称、下载中心、设置，以及最小化、最大化/还原、关闭按钮；空白区域可拖动窗口。 |
| 左上角影像检索面板 | 设置研究区、日期、产品及其他筛选条件。 |
| 检索面板下方 | 查看进度、提示和树状影像结果，勾选下载项。 |
| 地图画布 | 查看研究区和影像覆盖范围，拖动平移、滚轮缩放。 |
| 地图右上角 | “地名与道路”开关，仅控制参考地图显示，不改变检索条件。 |
| 顶部“下载”下拉面板 | 查看任务、暂停或继续下载、清空记录、清理临时空间。 |

## 4. 设置保存目录、账号与传输参数

点击 **设置** 打开“下载设置”。

### 4.1 文件保存

1. 在“保存目录”中填写路径，或点击文件夹按钮选择目录。
2. 根据需要勾选 **按卫星和产品分类保存**。
3. 点击 **保存设置**。

目录设置影响新建任务，不会自动搬移已下载文件或已创建任务的文件。确认具体位置时，以任务卡片的 **打开目录** 按钮为准。

### 4.2 Earthdata 账号

- 同时填写用户名与密码；眼睛按钮可切换密码显示。
- 点击“保存设置”后，账号和配置会持久保存，密码由操作系统凭据管理器保存。
- 如需移除保存的账号，点击 **清空账号**，再点击 **保存设置**。
- 点击“取消”或关闭设置窗口，不会保存本次草稿。
- 如果凭据读取失败，其他设置仍可能正常恢复；按提示重新填写密码并保存。

仅保存目录等其他配置时，可以同时留空用户名和密码；开始下载前仍需补齐账号。

### 4.3 传输参数

| 参数 | 范围与含义 | 初次使用 |
|---|---|---|
| 同时下载数 | 1–32 的整数，控制同时处理的文件任务数量。 | 沿用默认值 3。 |
| 单文件连接数 | 1–64 的整数，控制单文件并行传输配置。 | 沿用默认值 8。 |
| 限速（MiB/s） | 0 表示不限速；设置正整数可限制下载速度。 | 不需限速时填 0。 |

设置的是上限，实际连接数还受服务器能力、文件分块及共享请求预算影响。不要把“32 个文件 × 64 个连接”理解为一定会建立 2048 个连接。修改设置不会立即重设已经运行中的传输；新启动或继续的任务使用启动时的配置。

## 5. 选择研究区域

研究区用于筛选相交的影像，**不表示把下载文件自动裁剪到研究区**。当前独立下载器下载选中的整景产品，或选中的单个 Burst 及其元数据。

### 方式一：手动框选

1. 点击 **手动框选**。
2. 在地图拖动形成矩形，或依次点击矩形的两个对角点。
3. 核对面板中的经纬度。
4. 若要取消尚未完成的框选，按 **Esc**。

### 方式二：输入经纬度

按输入框方位填写：西 W、东 E 为经度，南 S、北 N 为纬度。

- 经度范围：−180° 至 180°；纬度范围：−90° 至 90°。
- 西经度必须小于东经度，南纬度必须小于北纬度。
- 西经和南纬用负数表示，例如西经 99° 填 `-99`。
- 示例矩形：W `-99.25`、E `-98.90`、S `19.25`、N `19.60`。
- 跨越 ±180° 经线的范围不能直接写成西大于东的矩形，应拆为两次查询。

### 方式三：行政区划

点击 **行政区划**，依次选择可用的省、市、县。该方式使用行政区的**外包矩形**，并非精确行政边界；需要精确多边形时请导入边界文件。

### 方式四：导入边界文件

点击 **边界文件**，选择研究区文件。

| 格式 | 操作要求 |
|---|---|
| GeoJSON / JSON | 文件内容为有效面或多面边界，使用 WGS84 经纬度坐标。 |
| KML / KMZ | 使用包含面边界的文件；KMZ 优先读取 `doc.kml`，否则应只有一个 KML。 |
| Shapefile（`.shp`） | 桌面端选择单个 SHP，自动读取同一目录下同名 PRJ。 |
| Shapefile ZIP | 压缩包中只放一套 Shapefile，并包含有效 PRJ。 |

例如选择 `study_area.shp` 时，应在同一文件夹保留 `study_area.prj`；建议将 SHP、PRJ、DBF、SHX 等配套文件一起保存。缺少或无效 PRJ 时，不要通过改文件扩展名或猜测投影绕过检查。

边界仅接受面，不会把点或线自动变为研究区。支持多面及孔洞；单次输入文件总量不超过 20 MiB，解压后的边界不超过 64 MiB。

导入后可点击 **改用矩形**，切换为外包矩形范围；直接修改经纬度也会清除原精确边界。

## 6. 设置检索条件

### 6.1 日期

日期以 `YYYY.MM.DD → YYYY.MM.DD` 显示，可输入或使用日历选择。开始日期不能晚于结束日期。影像详情中的采集时间标注为 **UTC**，与本地时间可能不同。

首次打开且日期为空时，应用会填入最近约 30 天；点击“重置”后会清空条件，需要重新设置。

### 6.2 产品类型

| 产品 | 下载内容 | 选择时注意 |
|---|---|---|
| Sentinel-1 SLC | 整景 SLC ZIP 文件。 | 需要后续解压或交给处理软件读取。 |
| Sentinel-1 BURST | 单 Burst TIFF 与对应共享 XML。 | 适合准备后续 Burst 处理或 burst2safe 输入。 |
| NISAR RSLC | L1 RSLC 整景 HDF5 文件。 | 选择雷达坐标复数产品时使用。 |
| NISAR GSLC | L2 GSLC 整景 HDF5 文件。 | 选择地理编码复数产品时使用。 |

其他条件包括 **S1卫星、轨道方向、极化方式**。不确定时先使用“不限”，再根据结果收紧条件。参数之间存在兼容规则；切换产品或卫星后，应用可能自动调整不兼容选项，请留意提示。NISAR 不适用的 Sentinel-1 筛选项会禁用或重置。

## 7. 检索、取消与查看结果

1. 点击 **检索**，查看各产品的处理进度。
2. 结果可能分批出现；以本轮检索结束为最终确认，不要把中途预览当作完整目录。
3. 等待时间较长或选错条件时，点击 **取消检索**。出现“取消中…”后，等待后台停止。
4. 取消后恢复本次查询前的结果和勾选；此前没有结果时恢复为空。检索失败也会恢复上次完整结果。
5. 查询期间不能修改条件或重置；取消结束后再修改并重新检索。

若出现“条件已修改，结果仍为上次检索”，表示当前列表尚未按新条件更新，需要再次点击“检索”。

### 7.1 浏览树状结果

- 展开分组查看产品及各景影像，使用 **全部展开／全部折叠** 调整列表。
- 点击一景的日期或名称可定位影像；详情按钮可查看标识、文件名、时间等信息。
- 点击地图影像足迹可标记当前影像，点击地图空白处可取消标记。
- **地图标记与下载勾选是两件事**：查看影像不等于选择下载；取消地图标记不会清除下载勾选。
- 使用复选框选择单景、分组或全部结果；下载前核对“已选 N 景”。

### 7.2 导出检索结果

勾选影像后点击 **导出所选 GeoJSON**，选择保存位置。导出期间按钮显示“导出中…”，避免重复打开保存流程。

导出的是所选影像的覆盖范围和属性，不是雷达影像文件，也不是裁剪后的 SAR 数据。

## 8. 下载与任务管理

点击 **下载所选（N 景）** 后，应用创建任务并尝试自动开始。若缺少账号，将提示打开设置；补齐并保存后，在下载中心点击继续或“全部开始”。重复任务可能被跳过，请查看操作提示。

### 8.1 识别任务状态

| 状态 | 含义与操作 |
|---|---|
| 待下载／排队中 | 已创建，等待启动或可用传输资源。 |
| 连接中 | 正在连接数据服务；Burst 文件可能需要服务端准备。 |
| 下载中 | 正在接收数据，可查看进度与速度。 |
| 校验中 | 正在检查文件，通常无需网络传输；速度较低不一定是卡死。 |
| 保存中 | 正在完成最终文件发布，请等待。 |
| 已暂停 | 点击继续按钮，或“全部开始”。 |
| 失败 | 阅读卡片错误信息，解决原因后重试。 |
| 已完成 | 下载、当前适用的校验及保存步骤已完成，可打开目录。 |

### 8.2 常用操作

- **全部／进行中／已完成**：筛选显示哪些任务。
- **全部开始**：启动所有可启动的未完成任务，而不只是当前筛选下可见的任务。
- **全部暂停**：暂停活动任务。
- **单任务暂停／继续**：控制对应任务。
- **打开目录**：查看该任务的实际保存位置。
- 点击“下载”或面板外部可收起面板，**收起面板不会暂停下载**。

重启应用后会恢复任务记录，中断任务通常变为暂停；点击继续后再传输，不会仅因打开应用就自动开始所有中断任务。

续传依赖服务器对文件身份和分段请求的支持。若无法确认旧数据与远端属于同一文件，应用可能从头下载，而不是拼接不可靠的数据。

## 9. 下载后得到什么

### Sentinel-1 Burst

新任务下载 `.tiff` 和 `.xml`。多个 Burst 可能共享同一源 SLC、同一极化的 XML，因此 **TIFF 数量与 XML 数量不一定相等**。

将相关 TIFF 与 XML 保持在同一目录，保留原文件名，供后续处理软件识别。当前下载器不负责把它们合成为 SAFE。历史版本下载的 ZIP 可能仍保留在目录中，不代表新任务仍按 ZIP 下载。

### 文件校验的含义

应用检查长度、本地摘要和适用的文件结构；数据目录提供 MD5／SHA-256 时还会比对供应商摘要。Burst 任务另行检查 TIFF 与 XML 的对应关系。

“已完成”代表通过当前下载器适用的检查，**不代表已完成科学数据质量验收**，也不等于对所有 ZIP 成员做完整 CRC 验证或对所有 HDF5 科学数据逐项检查。

## 10. 清空记录与空间清理

这两个操作的用途不同：

| 操作 | 是否停止任务 | 是否删除下载成果 | 是否释放临时空间 |
|---|---|---|---|
| 移除单条记录 | 活动任务需先暂停。 | 否。 | 不主动清除续传数据。 |
| 清空记录 | 会停止相关任务并清除记录，包含筛选隐藏的任务。 | 否。 | 保留本地文件和续传数据。 |
| 空间清理 | 不用于暂停正常下载。 | 不清理已下载成果。 | 按预览与勾选删除已移除任务的可清理残留。 |

操作“空间清理”时：

1. 先确认当前设置的下载目录是要检查的目录。
2. 打开 **下载 → 空间清理**，等待扫描。
3. 查看文件路径、类型和大小，勾选需要清理的项目。
4. 点击 **清理所选（N）**，查看释放空间和失败提示。
5. 若提示文件已变化或预览失效，点击 **重新扫描** 后再操作。

清理临时文件可能失去相应的续传进度。仍被任务引用的文件、下载成果、共享 XML 及校验记录会保留；不要手动删除正在下载的临时目录。

## 11. 常见问题

| 现象 | 处理方法 |
|---|---|
| 找不到影像 | 核对范围和日期；暂时放宽轨道、极化、卫星条件；确认所选产品在该日期和区域有数据。 |
| 检索等待较久 | 查看各产品进度；可取消后缩小区域、缩短日期范围或减少产品类型。 |
| 取消后新出现的结果消失 | 这是恢复上次完整结果的行为，本轮未完成预览不会保留为最终结果。 |
| SHP 导入失败 | 核对同目录同名 PRJ 是否存在、投影是否有效，以及文件是否为面边界。 |
| 地图标记已清除，但“已选”数量不变 | 地图标记不等于下载勾选；需要取消结果复选框。 |
| 下载提示账号或权限错误 | 检查 Earthdata 用户名、密码及数据服务访问权限，重新保存后继续任务。 |
| 任务已创建但显示同步失败 | 不要急于重复添加；打开下载中心核对任务，等待下一次刷新，按需点击继续。 |
| 传输完成后一直“校验中” | 等待校验；耗时与文件结构、磁盘速度和配套元数据有关，不只取决于文件大小。 |
| 下载大小最初未知或后来变化 | 以实际响应为准，特别是服务端生成的 Burst 文件。 |
| 文件已存在 | 应用不会直接覆盖；核对原文件、已有任务及保存目录，按提示处理。 |
| 磁盘空间不足 | 选择空间更充足的目录用于新任务，或通过空间清理检查可删除残留。 |
| 底图加载失败 | 使用界面中的“重试”；底图与 SAR 检索相互独立，仍可填写经纬度或导入边界。 |
| 更新后“取消检索”不可用 | 退出旧桌面进程，运行包含新后端命令的完整新版本；开发环境需重新编译并启动。 |

## 12. 遇到问题时提供哪些信息

向维护人员反馈时，请提供：产品类型、日期范围、研究区、所点按钮、完整错误文字、任务文件名，以及应用版本或更新时间。下载问题可补充保存盘剩余空间和任务状态。

无需提供账号密码。若附截图，先遮挡账号等不必要的个人信息。
